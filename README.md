# TD_Microfrontend_FE_angularjs

Standalone Angular frontend for the **Micro-Frontend Platform** project
type — a real multi-component remote (widget list/detail, remotes
panel, real HttpClient service), not a single bare component.

Not connected to any backend or React app by default. The paired
standalone backend lives in `TD_Microfrontend_BE_nodejs`, and the
React shell in `TD_Microfrontend_FE_reactjs`. The fully connected
version lives in `TD_Microfrontend_BE_nodejs_FE_reactjs_FE_angularjs`.

See ARCHITECTURE.txt for build commands and module layout.

Branches: one per Angular version (16, 17, 18, 19).
