ARCHITECTURE
============
This is the Angular remote of the Micro-Frontend Platform, standalone
- a genuine multi-component app (list/detail/remotes panel + a real
service layer), not a single bare component. In the connected repo
its build output is embedded live into the React shell via
<iframe src="/angular-remote/">; that React shell isn't present in
this single-technology repo (see TD_Microfrontend_FE_reactjs).

  src/app/lib/widgets.ts                pure widget logic
  src/app/services/widget.service.ts     real HttpClient service (widgets + remotes)
  src/app/components/widget-list.component.ts
  src/app/components/widget-detail.component.ts
  src/app/components/remotes-panel.component.ts
  src/app/app.component.ts               composes the above
  quality/                               21 real TypeScript code-quality tool fixtures
